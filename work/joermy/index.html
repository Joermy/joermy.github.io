Überblick

Joermy ist eine Electron-App, die einen KI-Agenten auf dem eigenen Rechner betreibt. Das Sprachmodell liegt als GGUF-Datei auf der Platte und läuft über llama-server auf der Grafikkarte. Der Agent liest und schreibt Dateien, führt Befehle aus, sucht im Netz, bedient auf Wunsch den Windows-Desktop und liest einen eigenen Wissensspeicher.

Die Aufgabe

Die meisten KI-Werkzeuge sind an einen Anbieter gebunden, brauchen einen Schlüssel und laufen im Browser. Wer an lokalen Projekten arbeitet, gibt damit bei jeder Anfrage Dateiinhalte aus der Hand — und zahlt pro Aufruf.

Der Ansatz

Eine Desktop-App, in der das Modell selbst auf dem Rechner liegt. Austauschbar über einen Modellordner, ohne Schlüssel, ohne laufende Kosten, ohne Verbindung nach außen, solange keine Websuche angestoßen wird.

Das System

Electron als Anwendungsrahmen, llama-server für die Modellausführung, lokale Datenhaltung für Chats und Projektordner. Die Automatik bringt alle Layer auf die GPU und holt den größten Kontext heraus, der in den Speicher passt. Wer will, stellt in den Modell-Einstellungen alles von Hand ein: GPU-Layer, Kontextlänge, K- und V-Cache-Typ, Spekulatives Dekodieren. Gedanken, Antwort und geschriebener Code erscheinen live im Chat.

Das Ergebnis

Auf einer RTX 4060 Ti mit 16 GB gemessen: Qwen3.6 35B schreibt beim Programmieren mit rund 88 Tokens pro Sekunde, Qwen3.8 27B mit rund 30 bei 81.000 Tokens Kontext. Sechs lokale Modelle bauten eine Testaufgabe aus sechs Modulen vollständig fertig, bis alle 18 Tests grün waren.
